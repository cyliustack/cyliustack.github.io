# Warriors Hunter 3D - WebGL Game

A **3D first-person shooter** version of the Warriors Hunter game built with WebGL 3D graphics!

## 🎮 3D Game Features

- **3D Graphics**: Full 3D environment with perspective rendering
- **First-Person View**: Immersive first-person camera with mouse look
- **3D Enemies**: Warriors enemies rendered as 3D cubes with helmets
- **3D Laser Sword**: Green laser projectiles in 3D space
- **3D Environment**: Ground plane with grid pattern
- **Sound Effects**: Audio feedback for hits, swings, and enemy deaths
- **Dynamic Lighting**: Basic lighting system for 3D objects

## 🎯 How to Play

### Controls
- **WASD**: Move around in 3D space
- **Mouse**: Look around (first-person camera)
- **Left Click**: Attack with laser sword
- **Spacebar**: Pause/Unpause the game
- **R Key**: Reload weapon
- **Enter Key**: Restart game when game over

### Objective
- Survive as long as possible by shooting 3D Warriors enemies
- Each enemy destroyed gives you 100 points
- Avoid letting enemies touch you - they drain your health
- When your health reaches 0, the game ends

### Game Mechanics
- **3D Movement**: Full 3D movement with WASD keys
- **Mouse Look**: Click to lock mouse and look around
- **3D Combat**: Aim and shoot in 3D space
- **3D Enemies**: Black Warriors cubes that chase you in 3D
- **Laser Beams**: Green 3D projectiles with sound effects
- **Health System**: Green health bar in UI
- **Ammo System**: Limited ammo - reload with R key

## 🚀 Getting Started

1. Open `index3d.html` in a modern web browser
2. The game will start automatically
3. **Click on the game window** to lock your mouse for looking around
4. Use WASD to move and mouse to look around
5. Left click to shoot at the 3D Dinosaur enemies
6. Try to survive as long as possible!

## 🛠 Technical Details

- **Graphics**: WebGL 3D rendering with vertex and fragment shaders
- **Physics**: 3D collision detection and movement
- **Audio**: Web Audio API for real-time sound effects
- **Performance**: Optimized for smooth 60fps 3D gameplay
- **Controls**: Pointer lock for immersive first-person experience
